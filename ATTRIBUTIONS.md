## Changes and licence scope

Cloud2BIM: only the attributed geometry helpers in `cloud2bim_geometry.py` and `ifc_geometry.py` are adapted. Other upstream implementations and all model weights/datasets remain absent. External libraries are unmodified. Research references are credited without copying their publications.

SpatialLM backbones, encoders, released checkpoints and dataset each retain their own terms. The Qwen base licence does not replace the SpatialLM checkpoint licence. GPT4Point retains both its MIT file notice and its conflicting README declaration. PointLLM-R has Apache-2.0 repository code, a model card declaring MIT with retained upstream terms, and separate publication terms.

No upstream creator endorses Punctora by virtue of these credits. Each creator's warranty disclaimers remain in the supplied licence texts.
